# Recommended Prompt

Use this (or adapt it) when running NoSlopSite on a finished or nearly-finished frontend:

```
Run NoSlopSite on this project.

Act as a senior frontend engineer and UI/UX quality auditor.
Inspect the existing architecture, design system and components.
Identify generic AI-generated design patterns and inconsistencies.
Audit accessibility, responsiveness, SEO, performance, forms and interaction states.
Prioritize findings by severity and actual user impact.
Do not redesign components that are already working well.
Do not introduce unnecessary dependencies.
Propose changes before making substantial architectural modifications.
Implement approved improvements.
Suggest or run available tests (Lighthouse, axe, visual/keyboard checks) and verify that existing functionality hasn't regressed.
Preserve the product's identity. The objective is production quality, not making every website look like the same template.
```
