# Contributing to NoSlopSite

Thanks for wanting to improve the skill.

## How to contribute

1. Fork the repo
2. Add or improve rules in `noslopsite/references/`
3. Keep rules practical:
   - Clear **Why it matters**
   - Actionable **How to detect**
   - Concrete **How to fix**
4. Update `CHANGELOG.md`
5. Open a pull request

## Good rule format

```markdown
### rule-id
**Priority**: critical | high | medium | low
**Applies to**: frontend | backend | full-stack
**Why it matters**: ...
**How to detect**: ...
**How to fix**: ...
```

## Ideas for contributions

- Stack-specific examples (Next.js App Router, Tailwind, shadcn, Vue, etc.)
- More rules around payments, auth, dashboards, or real-time features
- Before/after examples in the `examples/` folder
- Better detection heuristics

## Questions

Open an issue for bigger changes or ideas.
